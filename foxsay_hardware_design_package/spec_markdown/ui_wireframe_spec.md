# FoxSay 2.0寸屏 (320x240) 纯触屏界面线框图与坐标规范 (LVGL 布局指南)

本规范为 **【立创·实战派 ESP32-S3】** 搭载的 **GT911 电容触摸屏**（分辨率定为标准 **320 x 240**）提供精确的**像素级布局坐标（X, Y, W, H）**与**触控手势逻辑**。

整个系统完全基于**纯触控手势 (Pure Touch-Gestures)** 驱动，彻底消除了对任何物理实体按键的依赖。

---

## 🎨 屏幕全局参数定义 (Global Specs)
*   **分辨率**: 320 (宽) × 240 (高) 像素
*   **坐标系**: 左上角为原点 `(0, 0)`，X 轴向右递增，Y 轴向下递增。
*   **默认色值**:
    *   背景巧克力色 `COLOR_BG`: `#151311` (`RGB: 21, 19, 17`)
    *   主色活力橙 `COLOR_PRIMARY`: `#F59E0B` (`RGB: 245, 158, 11`)
    *   文字温暖白 `COLOR_TEXT`: `#FFF7ED` (`RGB: 255, 247, 237`)
    *   辅助淡灰色 `COLOR_MUTED`: `#BFAFA6` (`RGB: 191, 175, 166`)
